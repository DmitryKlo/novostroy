# CIAN: локальный парсер и граница фактического пилота

На 2026-10-10 реализован **внутренний review-импорт**, а не массовый сбор CIAN и не публикация новых предложений на сайте. Два объявления, вручную наблюдавшиеся на открытых страницах через read-only viewer, нормализованы из [малого фактологического снимка](../data/property/cian_public_sample_20261010.json) в [неизменяемый локальный run](../data/property/cian/review-v1/runs/cian-review-f022d4daa722d203/manifest.json). Третья страница ЖК исключена как проектная карточка, не квартира. Зафиксированы две индивидуальные запрашиваемые суммы: 38 881 323 ₽ (ДДУ/застройщик) и 28 590 000 ₽ (переуступка/агентство), с отдельной ценой за м² и временем наблюдения. Сайт не подтверждает текущую доступность квартир; `availability=unknown`, `source_updated_at=null`, `rights_status=unknown`, `complex_id/unit_id/location=null`. Похожее имя ЖК или URL не превращается в подтверждённую запись нашего реестра. Проектные цены «от», ипотечные условия и цена за м² не становятся обычной ценой конкретной квартиры.

Манифест run фиксирует SHA-256 входа `754da9aa048306c23d231493a8a5ec3ac9b53d0fe3c0a366252c3ba141901f89` и двух JSONL-записей `f022d4daa722d20349831d7e1e4cf491cfe5e654f102b891451aca82fdacc2a5`. Рядом лежат CSV для просмотра, отчёт и append-only index; повтор той же команды возвращает `already_imported`, 0 новых и 2 дубля. История цен сохраняется отдельными наблюдениями по listing ID и timestamp, а не перезаписывает прошлую сумму. Файлы review закрыты для других пользователей хоста. Фактические счётчики: **2 наблюдения, 0 автоматических live-запросов, 0 импортированных публичных offers, 0 скачанных медиафайлов**.

Парсер [локального HTML](../sources/property/cian.py) работает только при отдельном rights manifest на обработку/хранение. Он извлекает цену лишь из одного явно связанного с URL объявления Offer JSON-LD либо согласованных канонических price metadata в RUB; чужая карточка, диапазон «от», условная цена или один per‑м² показатель не дают `unit_asking`. Сетевой сборщик отклоняет отсутствие разрешения, ограничивает URL, задержки, время и объём; **он не запускался против CIAN**. [Классификатор медиа](../sources/property/cian_media.py) принимает только URL, связанный с собственными подписью/полем изображения, различает квартиру/план этажа/фасад/обычное фото и оставляет неизвестное неизвестным. Любая найденная ссылка остаётся частным кандидатом с `fetch_status=not_requested` и `public_display_allowed=false`. Наблюдённые публичные подписи «Планировка», «План этажа», «3D-тур» не содержали проверенной связки с доступным файлом; фактических изображений и подтверждённой фасадной картинки нет.

[Независимый checker](../integration/check_cian_review.py) прошёл по финальному run: отдельная [private JSON Schema](../contracts/cian-review.schema.json), хеши/индекс/CSV/права файлов, точные цены и типы сделки, нулевая публикация, отрицательные случаи «от»/условий/per‑м²/будущей даты, synthetic HTML с чужой ценой и media semantics. Фокусные unit-тесты адаптера и медиа — **13/13**. HTML-проверки выполнены только на синтетическом fixture; настоящая разметка CIAN не была получена, так что нельзя заявлять проверенный live HTML extractor. Общие backend/web тесты повторно не запускались, потому что публичные API, каталог и UI не менялись.

Воспроизведение из корня проекта:

```bash
rtk python -m sources.property.cian import-observations data/property/cian_public_sample_20261010.json
rtk proxy .runtime/dev-env/bin/python integration/check_cian_review.py
rtk proxy python -m pytest sources/property/tests/test_cian.py sources/property/tests/test_cian_media.py -q
```

Для следующего этапа нужен разрешённый экспорт/партнёрский доступ с явным объёмом автоматического получения, хранения и показа цен и отдельными правами на планы и изображения. Пользователь сообщил, что такого доступа сейчас нет. [Аудит доступа](../docs/briefs/cian-source-access.md) фиксирует правила сайта/API и нестабильность страниц. До появления разрешённого входа реальный каталог остаётся без CIAN-предложений, а текущие два наблюдения доступны только для локального review.
