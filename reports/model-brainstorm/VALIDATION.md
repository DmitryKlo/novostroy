Новую корпусную модель не скачали/создали/лицензировали; внешние расходы $0 при уже разрешённом общем потолке $20. [Концепт](CONCEPT.md) — предложение до выбора пользователем варианта главного проектного слоя.

Воспроизводимая локальная проверка из корня проекта:

```bash
rtk proxy .runtime/dev-env/bin/python reports/model-brainstorm/build_index.py --check
rtk proxy .runtime/dev-env/bin/python -m py_compile reports/model-brainstorm/build_index.py
rtk proxy .runtime/dev-env/bin/python - <<'PY'
import re
from pathlib import Path
text = Path('reports/model-brainstorm/index.html').read_text(encoding='utf-8')
blocks = re.findall(r'<script(?: [^>]*)?>(.*?)</script>', text, re.S)
assert len(blocks) == 2
Path('.runtime/model-brainstorm-index-check.js').write_text(blocks[1], encoding='utf-8')
PY
rtk node --check .runtime/model-brainstorm-index-check.js
```

Первая команда заново читает только семь банков машинно, проверяет полный порядок/уникальность ID, пересчитывает точные нормализованные дубли и сравнивает байты генерируемых CSV/HTML с текущими файлами. Вторая проверяет Python; следующие две извлекают локальный JS и проверяют его синтаксис. Дополнительно `csv.DictReader` и JSON-блок автономного HTML дали одинаковые 2800 ID с непустым текстом; локальные ссылки семи основных Markdown-файлов существуют. Все эти проверки **PASS**; в продуктовом bundle этот скрипт не включён.

Уровень внешней проверки не повышать по красоте концепта: официальная спецификация АГР не даёт файл данного корпуса; публичный viewer не даёт лицензию; старый Estateline не сообщает нынешнюю стадию; котлован не равен надземному пятну; AI не восстанавливает подтверждённые метры. План на 30 корпусов и 3–5 глубоких кейсов **ещё не исполнялся**, новых FPS/байтов/погрешностей для будущих моделей нет. Публичный показ новых корпусов и выбор режима карты требуют отдельного решения после пилота.
