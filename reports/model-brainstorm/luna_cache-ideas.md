# Luna #1 — 400 вариантов для исследования моделей новостроек Москвы

Дата: 2026-10-09. Это идеи для поиска/получения/построения, не утверждения о наличии права или общегородского покрытия. В каждой строке условие или проверка обязательны. Публичный просмотр — только lead, пока отдельно не доказано право хранения, модификации и показа.

## Q1 — где найти готовую модель

### Сайты и материалы девелопера

- LC-Q1-001 Найти официальный 3D-генплан ЖК → зафиксировать URL/корпуса, спросить у владельца экспорт и лицензию.
- LC-Q1-002 Найти интерактивную карту с переключением очередей → проверить, выделены ли именно здания, а не картинка.
- LC-Q1-003 Проверить кнопку «вид сверху/3D» на странице проекта → исследовать публичные HTML/JS/обычные asset-запросы, не обходя авторизацию.
- LC-Q1-004 Искать раздел проекта «Архитектура» и полигональную сцену → отличить модель от галереи рендеров.
- LC-Q1-005 Проверить презентацию проекта от девелопера → убедиться, что файл содержит перспективную модель, а не только фасадный коллаж.
- LC-Q1-006 Сопоставить версию генплана из лендинга и декларации → запросить актуальный корпусной состав при расхождении.
- LC-Q1-007 Найти в карточке проекта отдельный тур по территории → выяснить у девелопера, кто владеет базовой геометрией.
- LC-Q1-008 Проверить презентацию для покупателей/инвесторов → хранить только адресную ссылку, пока правообладатель не разрешил копию.
- LC-Q1-009 Найти отдельные страницы очередей/корпусов → зафиксировать разницу между введёнными и проектируемыми зданиями.
- LC-Q1-010 Проверить официальное мобильное приложение проекта на 3D-сцену → запросить партнёрский export, не реверсить трафик.

### Проектные документы, публикации и конкурсы

- LC-Q1-011 Искать альбом АГР в официальной публикации → сверить адрес и дату решения с проектом.
- LC-Q1-012 Проверить опубликованный буклет АГР → определить, есть ли модель-файл либо только согласованные изображения.
- LC-Q1-013 Искать архитектурный конкурс по площадке → связать концепцию с итоговым заказанным проектом отдельно.
- LC-Q1-014 Проверить победителя конкурса и автора концепции → спросить, сохранился ли разрешённый massing-export.
- LC-Q1-015 Искать материалы публичных слушаний/обсуждений → считать 3D-картинки концепцией, пока не найдено утверждение.
- LC-Q1-016 Проверить приложение к договору КРТ/ППТ → найти схему корпуса и стадию, не считать схему BIM.
- LC-Q1-017 Найти официальный буклет визуально-ландшафтного анализа → установить, присутствует ли цифровая сцена участка.
- LC-Q1-018 Проверить портфолио архитектора по точному адресу → отличить реализованный проект от конкурсного предложения.
- LC-Q1-019 Сопоставить рендер из буклета с действующим генпланом → найти заменённые корпуса до импорта.
- LC-Q1-020 Проверить проектную документацию с фасадами/разрезами → попросить исходную модель у правообладателя, не моделировать по PDF без прав.

### Городские модели и АГР

- LC-Q1-021 Проверить, опубликована ли модель в городском контуре АГР → доступ через уполномоченный порядок, не считать публичной.
- LC-Q1-022 Поискать IFC-комплект АГР для конкретного адреса → подтвердить, что проект подпадает под действующие требования.
- LC-Q1-023 Проверить редакции московского требования IFC → не использовать старый высоко-/низкополигональный регламент как актуальный формат.
- LC-Q1-024 Найти публичный номер/дату АГР → запросить у заявителя соответствующий frozen export.
- LC-Q1-025 Проверить городской цифровой двойник в открытом режиме → зафиксировать только то, что реально видно без авторизации.
- LC-Q1-026 Проверить каталоги публичных 3D-слоёв Москвы → отделить городской mesh от конкретной новостройки.
- LC-Q1-027 Найти материалы «СтроимПросто» по объекту → подтвердить, что доступен именно проектный файл, не сервис проверки.
- LC-Q1-028 Проверить конкурс/каталог ЦИМ → различить типовую компонентную библиотеку и модель целого ЖК.
- LC-Q1-029 Искать городские проектные презентации по кадастровому номеру → проверить связь участка с корпусами.
- LC-Q1-030 Сверить городской 3D-силуэт с АГР → считать silhouette lead и запросить источник геометрии.

### ЕИСЖС и документные реестры

- LC-Q1-031 Найти карточку проекта в ЕИСЖС → извлечь идентификатор и застройщика, не ожидать BIM-вложения.
- LC-Q1-032 Проверить реестр изменений проектной декларации → выбрать последнюю редакцию для запроса модели.
- LC-Q1-033 Искать в разделе документов декларации связанные планы/презентации → фиксировать формат и владельца каждого файла.
- LC-Q1-034 Связать ЕИСЖС-дом с адресом из АГР → отсеять одноимённые проекты в соседних районах.
- LC-Q1-035 Использовать API ЕИСЖС как индекс моделей-кандидатов → сначала подтвердить доступ, схему и договор.
- LC-Q1-036 Найти карточку застройщика ЕИСЖС → составить официальный список его проектов для проверки на 3D.
- LC-Q1-037 Сопоставить номер разрешения на строительство с проектной страницей → устранить путаницу очередей.
- LC-Q1-038 Проверить проектные документы на упоминание проектировщика → найти возможного держателя исходной модели.
- LC-Q1-039 Найти адресный строительный проект по номеру разрешения → подтвердить совпадение с рекламным названием ЖК.
- LC-Q1-040 Проверить, есть ли в публичном пакете машинно-читаемая геометрия → не принимать PDF-изображения за модель.

### Архитекторы, проектировщики и BIM-команды

- LC-Q1-041 Искать бюро, указанное автором АГР → подтвердить авторство конкретного корпуса, а не всего квартала.
- LC-Q1-042 Проверить BIM-портфолио бюро по адресу ЖК → установить, выполняло ли оно 3D-модель для нужной стадии.
- LC-Q1-043 Найти генпроектировщика в декларации/разрешении → запросить, кому принадлежит экспортная копия.
- LC-Q1-044 Проверить subcontractor-портфолио АР/КР → не считать BIM-подрядчика владельцем авторских прав.
- LC-Q1-045 Сопоставить названия корпусов с BIM-кейсом бюро → проверить точный лот и дату сдачи работ.
- LC-Q1-046 Искать модели по идентификатору проекта и названию бюро → отбрасывать зарубежные тёзки.
- LC-Q1-047 Проверить BIM-референсы проектировщика → запросить только внешний архитектурный LOD без внутренних сетей.
- LC-Q1-048 Найти автора благоустройства в проектной команде → отдельно искать разрешённую landscape-модель.
- LC-Q1-049 Проверить, кто проектировал фасады → потенциальный держатель фасадных текстур, права уточнить.
- LC-Q1-050 План потенциального контакта с координатором ЦИМ проекта → если такой контакт позднее будет отдельно разрешён, запросить карту состава/версий; до контакта это только гипотеза, не источник и не полученный доступ.

### Студии визуализации и маркетинговые производства

- LC-Q1-051 Найти студию рендеров по credit в буклете → спросить о праве передать mesh, текстуры и сцену.
- LC-Q1-052 Проверить сайт визуализатора по точному ЖК → отличить рекламную сцену от BIM/рабочей модели.
- LC-Q1-053 Найти подрядчика интерактивного генплана по legal credits → запросить только официальный SDK/export.
- LC-Q1-054 Проверить студию 3D-тура → выяснить, есть ли в сцене только panorama-поинты или геометрия здания.
- LC-Q1-055 Искать авторов архитектурной анимации проекта → установить владельца master-файла отдельно от продакшна.
- LC-Q1-056 Проверить презентацию подрядчика на список исходных форматов → не предполагать наличие IFC по одному рендеру.
- LC-Q1-057 Найти производителя виртуального офиса продаж → спросить о лицензированной веб-версии сцены.
- LC-Q1-058 Проверить, не является ли viewer набором 360-фото → оценить пригодность для геопривязанного объекта.
- LC-Q1-059 Сопоставить визуализатора с юридическим лицом договора → запросить разрешение у уполномоченного владельца.
- LC-Q1-060 Проверить у студии версионность проекта → не брать устаревший конкурсный вариант.

### Лицензированные внешние и профессиональные витрины

- LC-Q1-061 Проверить партнерский кабинет объявлений на 3D-вложения → использовать только договорно разрешённый API.
- LC-Q1-062 Проверить девелоперский каталог в дом.рф → разделить данные проекта и файл-модель.
- LC-Q1-063 Найти проектный viewer по домену застройщика → не копировать сторонний виджет без лицензии.
- LC-Q1-064 Проверить опубликованный 3D-макет у архитектора → установить лицензиара и право на web-показ.
- LC-Q1-065 Искать модель в профессиональной BIM-библиотеке → фильтровать типовые элементы от здания целиком.
- LC-Q1-066 Проверить коммерческие asset-каталоги по названию ЖК → использовать как lead, не считать их чистоту прав подтверждённой.
- LC-Q1-067 Найти официальный файл через поисковый индекс → открыть страницу правообладателя, не доверять зеркалу.
- LC-Q1-068 Проверить упоминание CAD/BIM платформы в кейсе → запросить выданный клиентом export, не обходить облачный доступ.
- LC-Q1-069 Искать презентацию инвестора с приложенным massing → уточнить, разрешён ли внешний продуктовый показ.
- LC-Q1-070 Проверить наличие публичной лицензии в карточке модели → сохранить именно текст лицензии и редакцию.

### Шоурумы и офлайн-визуализаторы

- LC-Q1-071 Проверить публично демонстрируемый киоск в официальном офисе продаж → попросить ссылку/asset и право на повторное использование.
- LC-Q1-072 Найти пресс-релиз о цифровом шоуруме → выяснить, кто поставил и лицензирует модель.
- LC-Q1-073 Проверить, доступна ли сцена покупателю через QR → открыть только публичный путь и условия.
- LC-Q1-074 Искать VR-презентацию комплекса → уточнить, можно ли получить внешний LOD отдельно от приложения.
- LC-Q1-075 Проверить макет квартала в офисе продаж → использовать его для списка корпусов, не оцифровывать без согласия.
- LC-Q1-076 Найти стенд с интерактивным генпланом → попросить демонстрационный экспорт через официальный контакт.
- LC-Q1-077 Проверить агентскую презентацию ЖК → найти первоисточник и точную дату версии.
- LC-Q1-078 Спросить канал продаж о владельце модели → направлять формальный запрос только после отдельного решения.
- LC-Q1-079 Найти видеопрезентацию с поворотом модели → определить корпусные отношения, не извлекать кадры для коммерческого mesh.
- LC-Q1-080 Сверить офлайн-макет с последним публичным генпланом → записать разницу как повод обновления.

### Проверка существования, качества и применимости

- LC-Q1-081 Разделить «видна 3D-сцена» и «получен редактируемый файл» → требовать источник файла.
- LC-Q1-082 Проверить геопривязку модели в метаданных → без CRS/anchor не считать её готовой к карте.
- LC-Q1-083 Проверить дату фиксации модели → исключать проекты, где корпусный состав уже изменён.
- LC-Q1-084 Сверить число корпусов модели с текущей декларацией → выявить неполное покрытие очередей.
- LC-Q1-085 Проверить степень детализации фасада → понять, нужен ли внешний low-poly export.
- LC-Q1-086 Проверить наличие отдельного mesh каждого корпуса → выбирать возможность этапной загрузки.
- LC-Q1-087 Проверить единицы и вертикальный datum → отложить импорт до устранения неоднозначности.
- LC-Q1-088 Проверить в проектном пакете атрибуты `building id` → оценить устойчивое сопоставление с реестром.
- LC-Q1-089 Проверить, охватывает ли модель благоустройство → не достраивать окружение как факт.
- LC-Q1-090 Проверить, моделируются ли стадии строительства → отличить конечный вид от временного этапа.

### Масштабирование поиска и подтверждение источника

- LC-Q1-091 Приоритизировать ЖК с официальным 3D-genplan → ежеквартально перепроверять URL и очередь.
- LC-Q1-092 Приоритизировать действующие московские BIM-кейсы → подтвердить именно жилое назначение и корпус.
- LC-Q1-093 Искать по адресу, кадастровому номеру и названию вместе → снижать ложные совпадения.
- LC-Q1-094 Дедуплицировать модели по хэшу только у лицензированного пакета → хранить provenance для каждого файла.
- LC-Q1-095 Искать по строительному номеру корпуса → сверять его с публичным адресообразованием.
- LC-Q1-096 Отмечать источник как `developer_viewer`/`architect_portfolio`/`city_document` → не смешивать типы доказательств.
- LC-Q1-097 Составлять карту контактов правообладателей по документам → не писать им до отдельного решения root.
- LC-Q1-098 Проверять доступность демонстрации на телефоне → не делать вывод о качестве экспортируемого файла.
- LC-Q1-099 Вести статус «нашли», «просмотрели», «получили файл», «лицензия проверена» отдельно → не пропускать правовой gate.
- LC-Q1-100 Останавливать lead, если источник не подтверждает корпус/дату/правообладателя → не переносить предположение в каталог.

## Q2 — как получить файлы модели и параметры

### Прямой экспорт от владельца проекта

- LC-Q2-001 Запросить у застройщика внешний LOD в GLB/glTF → условие: письмо/договор разрешает хранить и показывать.
- LC-Q2-002 Попросить IFC дисциплины АР без инженерных сетей → условие: выгрузка санкционирована владельцем ЦИМ.
- LC-Q2-003 Попросить OBJ/FBX только как промежуточный источник → до использования согласовать конверсию и текстуры.
- LC-Q2-004 Заказать геопривязанный экспорт с заданным origin/CRS → проверить контрольными координатами участка.
- LC-Q2-005 Получить отдельные файлы корпусов → подтвердить, что деление совпадает с адресами и очередями.
- LC-Q2-006 Попросить облегчённый внешний фасадный LOD → измерить размер и силуэт на мобильном тесте.
- LC-Q2-007 Запросить параллельно coarse и detail LOD → проверить общий anchor и одинаковую геометрию основания.
- LC-Q2-008 Попросить цифровой план благоустройства → держать его отдельным слоем с датой проекта.
- LC-Q2-009 Согласовать GLB и исходный IFC как две версии → сохранить цепочку преобразования и автора экспорта.
- LC-Q2-010 Получить sample одного корпуса перед портфельным договором → подтвердить формат, координаты, права и обновление.

### Официальная подача АГР/ЦИМ

- LC-Q2-011 Попросить у заявителя законно переданный IFC АГР → подтвердить право экспортировать копию третьему лицу.
- LC-Q2-012 Использовать IFC/BCF/XML только в составе разрешённого пакета → не извлекать закрытый пакет из кабинета.
- LC-Q2-013 Запросить ведомость моделей и version IDs → связать объектную геометрию с корпусом и очередью.
- LC-Q2-014 Попросить высоко-/низкополигональные варианты по текущему московскому стандарту → сверить действующую редакцию.
- LC-Q2-015 Получить TRM/чертежные виды только если лицензия покрывает отображение → проверка правообладателя обязательна.
- LC-Q2-016 Сопоставить дату АГР с фактической редакцией для строительства → установить, не заменён ли проект.
- LC-Q2-017 Запросить у автора выгрузку без внутренних атрибутов → удалить чувствительные свойства до передачи.
- LC-Q2-018 Получить внешний корпусный IFC вместо инженерного комплекта → минимизировать лишние данные и размер.
- LC-Q2-019 Попросить подтверждение координатной системы и высотного datum → испытать round-trip в тестовой сцене.
- LC-Q2-020 Зафиксировать, что АГР-подача не равна public license → отдельно получить право продукта.

### GIS ОГД и проектные документы

- LC-Q2-021 Скачать доступную карточку документа через официальный GISOGD UI → сохранить дату, номер и оригинальный URL.
- LC-Q2-022 Выгрузить разрешённый SHP слоя проекта межевания → проверить схему/CRS перед пространственной стыковкой.
- LC-Q2-023 Получить PDF/графику генплана из карточки → не перекрашивать/публиковать её без выяснения прав.
- LC-Q2-024 Запросить выписку по конкретному участку через mos.ru-доступ → не использовать чужую учётную запись.
- LC-Q2-025 Использовать фильтр по кадастровому номеру в GISOGD → проверить, что выбран документ именно ЖК.
- LC-Q2-026 Сохранить номер и редакцию ППТ/ПМТ → получить прежний/новый документ, если границы расходятся.
- LC-Q2-027 Взять открытые геометрические контуры для привязки модели → сравнить с официальной системой координат.
- LC-Q2-028 Запросить недоступный слой официальным способом → включать его только после письменного ответа/разрешения.
- LC-Q2-029 Получить документы через публичный download button → фиксировать, что интерфейс дал именно этот файл.
