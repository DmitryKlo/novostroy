## Q2 — Как получить или выгрузить файлы и параметры

001. **LL-Q2-001** — Скачивать оригинальный PDF с первичного портала → сохранять исходный URL, дату доступа и контрольную сумму.
002. **LL-Q2-002** — Сохранять карточку источника рядом с каждым файлом → записывать автора, тип документа, редакцию и статус.
003. **LL-Q2-003** — Использовать только документированный экспорт портала → не имитировать закрытый API и не обходить вход.
004. **LL-Q2-004** — Разделить исходник и производные страницы → OCR, поворот и обрезку хранить как отдельные артефакты.
005. **LL-Q2-005** — Извлечь страницы PDF с таблицей экспликации → проверить номера корпусов вручную по листу.
006. **LL-Q2-006** — Снимать PDF-метаданные и закладки → сравнить дату, состав томов и номера листов.
007. **LL-Q2-007** — Из векторного PDF извлекать контуры без растрирования → сверить масштаб с размерной линией.
008. **LL-Q2-008** — Для скана создавать калибровочный растр → проверить минимум две размерные длины в разных направлениях.
009. **LL-Q2-009** — Переписывать координатную систему из штампа листа → остановить геопривязку, если МСК-зона не названа.
010. **LL-Q2-010** — Экспортировать разрешённый DWG в DXF/GeoPackage → зафиксировать версию конвертера и исходные units.
011. **LL-Q2-011** — Экспортировать разрешённый IFC 4.3 с геопривязкой → проверить IfcMapConversion и вертикальный datum.
012. **LL-Q2-012** — Принимать FBX АГР как отдельный формат источника → сверить МСК Москвы, метры и абсолютные высоты.
013. **LL-Q2-013** — Сохранять прилагаемый GeoJSON из модельного пакета → сопоставить его с FBX по адресу и имени корпуса.
014. **LL-Q2-014** — Читать project declaration только по нужным полям → записать этажность, площадь, сроки и дату декларации.
015. **LL-Q2-015** — Выгружать перечень корпусов из приложения → хранить исходное написание и нормализованный ключ отдельно.
016. **LL-Q2-016** — Извлекать номера разрешений из титульников → связывать документы по номеру, не по бренду.
017. **LL-Q2-017** — Прочитать основные параметры из ГПЗУ → маркировать предельные параметры как лимиты, а не проектные размеры.
