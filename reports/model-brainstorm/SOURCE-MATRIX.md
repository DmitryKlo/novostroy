# Матрица источников и доказательств для будущей модели корпуса

Дата: 2026-10-09. Сводка по [семи briefs](DEBATE.md) и уже существующим локальным данным; Sol-Max не пересматривал каждую внешнюю страницу самостоятельно. Уровни ниже относятся к **каналу**, не автоматически к любому московскому ЖК. Для конкретного корпуса всегда нужен свой паспорт.

`D` = источник обнаружен; `T` = текст/страница прочитаны; `F` = разрешённый файл получен; `G` = его геометрия/параметры проверены; `R` = конкретное право публичного использования подтверждено. `G` не включает `R`, а `R` не доказывает метрическую точность. Отдельно фиксируются дата, корпусная идентичность и scope `receive/storage/derivative/web/iOS/CDN/expiry/revoke`.

## Операционный приоритет до закупок

| Вердикт | Каналы и причина | Проверка актуальности / автоматизации |
| --- | --- | --- |
| **Пилотировать бесплатно сейчас** | Локальный OSM/Overture для **существующего** контекста; открыто доступные декларации/проектные карточки для корпуса/даты; разрешённый масштабный план, если реально открыт и подходит по правам. EstateLine — только внутренний список кандидатов. | Заморозить 30 корпусов по стадиям; включить отсутствующие документы в знаменатель; автоматизировать только discovery/участок/очередь, корпус подтверждать экспликацией. Свежесть стадии проверять новым датированным источником. |
| **Зависит от доступа и владельца** | Добровольные IFC/DWG/GLB, конкретный пакет АГР/ГИС ОГД, официальный экспорт developer viewer. Это самый ценный путь к внешнему виду, но сегодня ни один корпусный файл+grant не получен. | Сначала правомерный канал, версия, корпус, CRS/датум и scope прав; лишь потом QA/LOD. Не строить массовый план на предположении, что кабинет/API доступен. |
| **Только существующие здания или контекст** | OSM/Overture, Microsoft ML footprints, датированные улицные фото, GHSL/DSM. | Проверять дату и совпадение существующего корпуса; не переносить параметры на котлован/будущую очередь. Автоматическая ML-высота не становится проектной отметкой. |
| **Отложить для размерной модели** | AI image-to-3D, скрытые viewer-ресурсы, извлечение 3D из картографических SDK, неосмотренный PDF Тайнинской. | AI/картинки могут быть только разрешённой неметрической иллюстрацией или visual reference; Тайнинская требует полного листа и прав. Лицензии платформ не заменять технической доступностью. |

Приоритет «пилотировать» означает **проверить возможность**, а не публиковать геометрию. Один канал может одновременно быть полезным для existing-city фона и непригодным для будущего корпуса.

| Канал | Уровень в нынешнем исследовании | Что может дать | Чего не доказывает / следующий gate |
| --- | --- | --- | --- |
| [Локальный EstateLine](../../data/property/estateline/source_manifest.json) | F для исторических записей, не G/R модели; права `user_supplied_internal_use`. | Внутренний список кандидатов, адрес, исторический статус/дата. | Не текущая стадия, не гос-ID корпуса, не footprint, не право публично распространять исходные XLSX. |
| [OSM/Overture building](https://docs.overturemaps.org/guides/buildings/) | Локальный existing-city ground геометрически проверен; связь с конкретным будущим корпусом не доказана. | Контекст построенного города, редкие height/floors/parts, проверка уже существующего объекта. | Котлован/будущий корпус и фасад; нужен per-corpus crosswalk, дата и соблюдение ODbL/атрибуции. |
| [Microsoft GlobalMLBuildingFootprints](https://github.com/microsoft/GlobalMLBuildingFootprints) | D/T по [RS brief](report_sources-brief.md), московский проектный срез не проверен. | Независимый сигнал для сравнения контуров/оценок. | Не проектная геометрия и не подтверждённая высота отдельного корпуса; проверить локальный срез/лицензию. |
| [ЕИСЖС / наш.дом.рф](https://наш.дом.рф/) | D/T по briefs; API в проверке RS вернул 403. | Декларации, разрешения, юридическая идентичность, датированные параметры. | Не обещает IFC/GLB, публичный API или право копировать чертежи; проверить допустимый канал и номер корпуса. |
| [АГР: технические требования Москвы](https://www.mos.ru/upload/content/files/Trebovaniya3DAGRitog.pdf) | T по [LL/SP briefs](luna_lod-brief.md), не F конкретной модели. | Ожидаемые состав/координаты/высоты подаваемого пакета. | Спецификация не подтверждает доступ, корректность и права файла данного корпуса. |
| [ГИС ОГД Москвы](https://gisogd.mos.ru/map) | D/T описания; доступ к нужному пакету не подтверждён. | Возможные документы, границы, координатные сведения через правомерный доступ. | Не публичная массовая BIM-библиотека; проверить авторизацию, доступность файла и reuse scope. |
| [СПОЗУ Тайнинской, 3](https://www.mos.ru/upload/documents/files/7627/Taininskaya3-5akt%281%29.pdf) | Только indexed discovery; полный PDF инструмент не открыл. | Кандидат масштабного листа и корпусной экспликации. | Не осмотренный размерный контур: сначала полный разрешённый файл, масштаб, два направления размеров, контрольные точки, CRS и права. |
| Официальные 3D viewer девелоперов | D; ПИК/Bpark read-only запрос 401, ФСК — HTML/изображения по [RS/LC](report_sources-brief.md). | Название проекта/очереди, визуальная подсказка, возможный держатель файла. | Ни скачанный GLB, ни точные габариты, ни license grant; классифицировать только обычные публичные запросы. |
| Добровольный IFC/DWG/FBX/GLB от правообладателя | Пока нет F для выбранного корпуса. | Лучший потенциальный внешний LOD и измеримые параметры после QA. | Пока гипотеза; нужны письменный scope, ID/версия, CRS/датум, независимый контроль и cost/time. |
| Официальный масштабный план + разрез | Пока нет F+G+R для нового пилотного корпуса. | Проектный footprint, секционные высоты и стилобат после калибровки. | Не готовый фасад и не текущая стройка; права на производную геометрию отдельно. |
| Датированные фото/ортоснимки/Mapillary | Описан канал, корпусная съёмка не проверена. | `observed_now`, проверка существующего фасада/стройки, иногда измеримая съёмка с контролем. | Не будущий корпус, не метры по одному кадру; нужны дата, права, камера/масштаб. |
| GHSL/Copernicus DSM | D/T по [RS brief](report_sources-brief.md), конкретный корпус не проверен. | Районный sanity check высот/рельефа. | Не проектная кровля и не разделение деревьев/зданий без дополнительного контроля. |
| Карты Yandex/2GIS/Google 3D | Внешние каналы отображения/визуального reference. | Контекст для ручной сверки при соблюдении правил платформы. | Не разрешённый экспорт в наш Cesium/GLB; ограничения хранения/извлечения проверять по правилам каждого сервиса. |
| AI image-to-3D / TripoSR | D/T метода, корпусный эксперимент не проведён. | Возможная неметрическая иллюстрация из разрешённого кадра. | Скрытые стороны, масштаб, размеры и фасад как факт. Hosted Tripo Pro $20/мес. при оплате $240 за год — вне общего $20 потолка. |

Правило публикации: для каждого корпуса и **каждой геометрической версии** нужны доказанная идентичность, измеренная погрешность там, где заявлены размеры, дата и соответствующее право на конкретную платформу. Источник может оставаться полезным для discovery или private QA после отказа в публичном GLB. Имена поставщиков публично показываются только согласно уже существующему server-side флагу; эта матрица — внутренний исследовательский документ, не предложение нового UI.
