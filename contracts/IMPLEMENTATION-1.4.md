# Local amenities and walking-route contract (v1.4)

`GET /v1/map/nearby?point_id=mappt_<24hex>&education=all|school|kindergarten` accepts only an ID from the current validated `/v1/map/points` snapshot. The API resolves its confirmed mapped coordinate; callers cannot send arbitrary coordinates. It returns separate `metro`, `education`, and `medical` layers with at most five POIs each. All three POI map layers are initially hidden in the web client. `GET /v1/map/nearby/viewport?bbox=west,south,east,north&layers=metro,education,medical&education=...&limit=150` returns a bounded marker slice without routes; width and height are each limited to 0.15°. Unknown IDs return 404; malformed IDs, filters, bounds, or caps return 422; an unavailable local worker or mismatched source snapshots returns 503.

`ranking_basis=straight_line` means candidates are selected by air distance to mapped source points. Their walking route and time are calculated afterward from the pinned local pedestrian graph. They are **not** the five globally shortest walking routes. The medical policy is explicit: if none of the nearest five has verified current OMS evidence, `selection_policy=nearest_four_plus_nearest_verified_oms` replaces the fifth candidate with the nearest verified OMS program participant. The verified site may be far away, so its displayed distance and route must remain visible. At most five medical items are returned, never six. If no verified participant survives source/date/identity checks, `free_clinic_guarantee.status=unavailable` means evidence is unavailable, not that free medical care does not exist. The badge confirms participation in the dated territorial program, not coverage of every service or unrestricted admission.

Every route has an explicit status. A walking distance, time, and geometry are present only for `routed`; a failed local graph query or an endpoint snapped over 50 m never becomes a guessed travel time. The mapped residential point is not a verified entrance. POI polygons use a representative source point unless a known access point exists; 228 metro stations have explicit relation-linked entrances in the current derivative. `route.approximate=true`, `endpoint_basis`, and `endpoint_note` preserve this limit. Route geometry is capped at 512 lon/lat pairs. The pinned OSM snapshot and required copyright attribution are in every response; POI completeness, live road closures, facility operation, school availability, clinic service eligibility, and device performance remain unverified.

Responses contain opaque point and POI IDs, no raw OSM IDs, provider URLs, source tags, or private records. Both routes use `private, max-age=0, must-revalidate` with weak ETag/304; source-exposed mode is no-store. `schemas.json` defines `NearbyPointResult` and `NearbyViewportResult`; `openapi.json` defines routes and errors. Unity DTOs are additive contract compatibility only. The native registry screen remains unsupported, so it does not display the new POIs or replace them with demo offers.
