# Acceptance cases для /models

План проверок, не выполненный тест-отчёт. Базовый fixture — 2317 входных source rows из manifest, не 2317 уникальных ЖК: 1473 принятых + 59 review EstateLine, 756 OSM construction, 27 сочинских событий и 2 упоминания газопровода.

1. **Полный охват.** Run выдаёт одну assessment на каждую из 2317 source rows с устойчивым candidate_id; scanned и сумма ready/review/rejected/unavailable равны 2317. Overture 564031 ground footprints не входят в этот знаменатель. Старые статусы EstateLine не становятся observed_now.
2. **Идемпотентность и дедуп.** Повтор той же строки/manifest/hash не создаёт вторую assessment или второй candidate_id; разные source namespaces и версии не сливаются по похожему имени/геометрии. Число входных rows отдельно от числа связанных проектов.
3. **Standalone OSM может отображаться.** Валидный OSM ID, геометрия и известные права ODbL дают own-ID shape с ready_to_render=true, entity_type=mapped_construction, registry_id=null, project_link_status=unlinked; плоский depiction=construction_outline допустим без высоты.
4. **Связь с ЖК — отдельное утверждение.** Без проверенного crosswalk не маркировать собственную mapped shape как конкретный ЖК/утверждённый проект. При этом отсутствие crosswalk само по себе не запрещает отображение разрешённой standalone геометрии; UI явно показывает unlinked.
5. **Ключ выбора — candidate_id.** List response не содержит asset URL. При выборе строки web запрашивает geometry только для этого candidate_id; nullable registry_id/project ID не мешает standalone отображению. При быстром выборе A→B запоздалый A игнорируется, ground остаётся смонтирован и видим.
6. **Выбор геометрии по состоянию.** ready_to_render=false всегда даёт model URL=null. ready URL допустим только после проверок геометрии и прав для собственного mapped shape; для утверждения проекта дополнительно нужны verified crosswalk, версия и право на соответствующее заявление.
7. **Отсутствует ≠ отклонён.** Нет individual asset → unavailable, а не rejected. Найденная гипотеза с конфликтом/неподтверждённым правом получает review/rejected и остаётся в экране проверки; отсутствие модели не превращается в quality=0.
8. **Причина понятна.** Каждый non-ready item имеет подходящий reason_code и непустой русский reason_text; экран показывает текст. Для исходов Sochi/gas использовать соответственно not_moscow_residential/non_building_infrastructure, не общий пустой отказ.
9. **География и тип.** Все 27 сочинских жилых событий и 2 газовых упоминания учтены в аудите 2317 rows, но не попадают в Moscow residential ready/markers; gas не становится ЖК. Валидные московские OSM construction из 756 не отклоняются только из-за отсутствия registry_id.
10. **Высота не выдумывается как факт.** При неизвестной высоте доступен только плоский контур. Отдельная оценка render-height может управлять schematic_massing только с явной меткой mapped_estimate; в source facts поле высоты остаётся неизвестным.
11. **Источник и HTTP cache.** При обычном startup-флаге source details скрыты; query/header не включает раскрытие. Source-exposed startup mode даёт Cache-Control: no-store. Без него public API имеет ETag и возвращает 304 для неизменённого ответа; reason_text остаётся публичным в обоих режимах.
12. **Инвалидация и mobile-контракт.** Новый run/asset hash меняет model_run_id или immutable asset URL; старый ответ не подменяет новый выбор. Возврат к тому же run может переиспользовать versioned asset без пересоздания Cesium ground. Native либо разбирает additive DTO по контракту, либо явно сообщает unsupported; он никогда не подставляет demo модель.

Offline runner, API/schema и web unit/UI тесты обязательны для этих случаев. Browser FPS, Unity Editor и iPhone проверяются отдельно; здесь ничего из этого не запускалось.
