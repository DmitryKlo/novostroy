# Проверяемый приём фасадных материалов — 10 октября 2026

`sources/facades/assessment.py` принимает **частные** наблюдения и локальные файлы. Он не ищет источники, не скачивает изображения, не создаёт фасадную 3D-модель и не меняет `data/models/active.json`, карты или публичные ассеты. Его выход — иммутабельный JSONL с причинами, по которым находку пока нельзя выдавать за подтверждённую модель корпуса.

## Реальный ограниченный прогон

## Алгоритм и предел доказательства

Приём ограничен 1000 строками, 64 KiB на строку, 32 MiB на файл по умолчанию, 2 MiB заголовка GLB. Локальные пути должны разрешаться внутри явно указанного `--input-root`; ссылки принимаются только как HTTPS без учётных данных и локальных/IP-хостов. Чтение не выполняет сетевой запрос. SHA-256 и длина сверяются с наблюдением. JPEG/PNG дают только пиксельные размеры; PDF/IFC распознаются по заголовку, а не по расширению. GLB требует glTF 2.0, BIN, треугольные примитивы с конечными POSITION и индексами внутри массива. Это проверка структуры, **не** метрическая поверка: даже указанные поставщиком единицы, CRS, datum, размеры и контрольные отрезки остаются заявлениями до независимой сверки. Панорама и фасадный чертёж требуют явной подписи; общий ЖК-альбом не превращается в фасад конкретного корпуса.

Прямая связь с корпусом требует его официального идентификатора/экспликации, версии решения и проверяемых ссылок. Совпадение участка или кадастра даёт только кандидата уровня ЖК/лота. Права внутреннего просмотра, хранения в продукте, публичного показа и производных различаются: успешный HTTP GET подтверждает доступность байтов, не лицензию. Непроверенные права, лица/интерьеры, версия или геометрия удерживают материал в review. Нельзя переносить текстуру с фотографии/рендера на существующий OSM-объём как «проверенный фасад»; без масштаба и связки с корпусом нельзя извлечь точные габариты.

Для будущего подтверждённого mesh нужны поставщик/лицензия на использование, корпусный ID и версия, отсутствие внутренних/личных данных, явные единицы/CRS/высотная система и независимые контрольные измерения фактической геометрии. Эти условия проверяются отдельно от данной автоматической предварительной оценки.

## Повторение

```bash
cd /home/pirojban/novostroy
rtk proxy .runtime/dev-env/bin/python -m unittest sources.facades.tests.test_assessment -v
rtk proxy .runtime/dev-env/bin/python -m sources.facades.assessment \
  --input data/research/facades/facade-intake-20261010.jsonl \
  --input-root data/research/facades \
  --output-dir data/research/facades/assessments
```

Повторный прогон с теми же байтами читает существующий content-addressed run и сверяет его содержимое; он не трогает active pointers. Тесты покрывают недостоверные GLB-индексы, подмену SHA, выход пути из корня, запрет прав, различение подписи и формата, а также запрет присваивать заявленным размерам статус измеренной модели.
