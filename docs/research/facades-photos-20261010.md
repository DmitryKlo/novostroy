# Фасады и открытые изображения: результаты поиска на 2026-10-10

## Короткий результат

В локальном реестре есть один хороший точный image-reference-кандидат, но пока нет проверенного права показывать его в продукте и нет 3D-файла. `estateline:3142639` — «Многофункциональный жилой комплекс (Корпус 33)», Автозаводская, земельный участок 23/436, кадастровый номер 77:05:0002005:3937; последний снимок источника — 2026-04-26, не подтверждение текущей стадии. Точное название и участок совпадают с [номинацией Lot 33 в Архитектурной премии Москвы](https://mosarchawards.ru/nominees/luchshee_arhitekturnogradostroitelnoe_reshenie_mnogokvartirnogo_zhilogo_doma_2025/mnogofunkcionalnyy_zhiloy_kompleks_s_podzemnoy_avtostoyankoy_lot_33_1004/) и [разрешением Москвы](https://www.mos.ru/upload/documents/files/2491/Spravkas2712po15012026.pdf). На сайте премии у карточки есть image-file `https://mosarchawards.ru/img/uploads/med/b1/b1f09f6661a1ba3ea2fe128332d14ce9.jpg`. Это проектная визуализация с точной привязкой к объекту, а не фотография построенного фасада и не glTF/BIM; у страницы указано ©, отдельная лицензия файла или право на публичное переиспользование не обнаружены. Для внутренней оценки формы кандидат полезен; до установления лицензии не класть его в public assets и не использовать как фотограмметрический донор.

В Commons есть пригодные **контекстные** кадры стройки Shagal, но пока нет строгой связи с корпусом одной EstateLine-строки. [Кадр «Marka Shagala 13..15 construction»](https://commons.wikimedia.org/wiki/File:Moscow,_Marka_Shagala_13..15_construction,_April_2025_12.jpg) — CC0, авторская съёмка, 18.04.2025, 4980×3320, 4.7 MB, Canon EOS Rebel SL1, 40 mm. Собственная подпись автора уточняет, что это кварталы 13 и 15 и «много десятков домов». Поэтому это потенциально полезный временной снимок района/стройплощадки, но не подтверждение фасада или состояния конкретного корпуса. Аналогично [подборка ZILART Tower](https://commons.wikimedia.org/wiki/Category:Zilart_Tower) содержит точно названные фото жилой башни по адресу б-р Братьев Весниных, 1, но местный EstateLine-лот 33 по участку 23/436 — другой объект; связь запрещена.

Проверила ещё несовпадающую по фазе запись `estateline:1548273` (Краснопресненская наб., вл.14, стр.1Б; «2-я очередь», 75 этажей; snapshot 2024-12-08) против [Commons Capital Towers](https://commons.wikimedia.org/wiki/Category:Capital_Towers), у которой каталожный адрес владение 14, строение 1. Для самого комплекса есть небольшой официальный файл [Capital Towers1.jpg](https://commons.wikimedia.org/wiki/File:Capital_Towers1.jpg) (Mos.ru, 2020, CC BY 4.0, 545×784) и позднейшая [съёмка 2024 года](https://commons.wikimedia.org/wiki/File:Moscow_-_Capital_Towers1.jpg) (авторская, CC BY 4.0, 4000×6000, 40 mm). Это лучшее найденное разрешённое фото конкретной высотной композиции, но адрес и стадия не доказывают, что именно вторая очередь/стр.1Б показана; следовательно, для этой EstateLine-строки остаётся `review`, не привязанный image. Сам корпусный ряд может быть уже после завершения внешне похожего/соседнего комплекса; текущий статус фото не доказывает.

Один raw sample сохранён: [CC0 Shagal JPG](../../data/research/facades/photos-20261010/raw/shagal-13-15-2025-04.jpg), 4,924,217 bytes, 4980×3320, SHA-256 `913b566ca417e3c7606c1f15f006f92d985d1be90bffc3e6ac956081b3eb9341`. URL и file-specific license пришли из [официального Commons `imageinfo`](../../data/research/facades/photos-20261010/commons-imageinfo.json); нормализованная карточка для assessment — [`commons-shagal-13-15-candidate.json`](../../data/research/facades/photos-20261010/commons-shagal-13-15-candidate.json). Визуальная проверка показывает широкий коридор стройки и несколько разных фасадов; не выделяет один корпус. В EXIF есть GPS IFD, но он содержит только версию, без координат; camera pose и масштаб отсутствуют. Первая попытка с вручную вычисленным URL `/9/9c/...` вернула 404 и остаётся только в `download_attempts_rejected` карточки без соответствующего asset. Официальный Lot 33 render не скачан: его загрузка была остановлена из-за несовпадающего TLS-сертификата hostname, проверку сертификата не отключали. Ни один материал не опубликован в `assets/`.

## Безопасный следующий шаг

1. Хранить исходники и source manifests только в `data/research/facades/photos-20261010/`: original page URL, direct asset URL, capture/source date, file SHA-256, source license/evidence URL, attribution, exact identity level (`corpus`, `estate`, `district`, `unknown`), view type (`photo`, `render`, `panorama`, `mesh`), EXIF/camera/scale/geo fields. Не пропускать asset на карту при уровне ниже `corpus` или неясном display right.
2. Commons CC0 Shagal frame уже сохранён и годится как estate/district context для pipeline/assessment; не прикреплять его к одной из EstateLine строк и не делать crop, который создаёт такое впечатление. Отдельно получить Lot 33 render только через URL/host с корректным TLS и сохранить как `render`, `identity=corpus`, `display_rights=unknown`; не создавать на его основе метрическую геометрию.
3. Для автоматизации проверить наличие Mapillary/KartaView sequence по уже подтверждённым точкам/адресам, сохранить API/author/date/license metadata и остановиться, если токен/доступ потребует user account. Не использовать автоматическое скачивание защищённых страниц или массовое зеркалирование.
4. Photogrammetry/3D candidate принимает только открытый или отдельно разрешённый набор с несколькими видами одного корпуса, хотя бы одним измеряемым масштабным отрезком/контрольной геометрией, source dates и единичной identity-link проверкой. До этого реальный фасадный mesh отсутствует.
