# Raster sources for building height and terrain

Review date: 2026-10-09. This is a source assessment, not an integration. No raster pixels were downloaded or added to the product.

## Finding

No reviewed raster source supports assigning a reliable height to each building footprint or to separate sections of one building. GHSL BUILT-H is an open, useful city-morphology prior, but each cell summarizes many buildings. Copernicus GLO-30 is a real, openly accessible Moscow DSM tile, but it measures the top surface of buildings, trees, and terrain on a nominal 30 m grid; it is not a building-height layer. FABDEM is a modeled terrain surface with building/tree bias removed and has a noncommercial share-alike license. No openly downloadable Moscow LiDAR point cloud or building-scale bare-earth/DSM product with reusable terms was identified in the official sources reviewed. Moscow's GIS OGD portal requires a mos.ru account, so any potentially relevant restricted layers remain gated.

The product should continue to distinguish source-observed building/part heights from render fallbacks. Raster cell values must not be copied onto every intersecting building or used to invent separate heights for building sections. A future raster role could be citywide context or a coarse quality-control prior, with source year, grid support and uncertainty shown explicitly.

## Why GHSL cell values are not building heights

For a cell, GHSL defines built volume `BUVOL`, net built surface `BUSURF`, and cell surface `S`. `ANBH = BUVOL / BUSURF` is an average over built surface; `AGBH = BUVOL / S` spreads the same volume over the entire cell. The JRC example gives a 100 m cell with 750 m² of built surface and 11.5 m ANBH, but only 0.8625 m AGBH. Therefore AGBH can be far below the height of any building in that cell. Neither statistic identifies which building produced the signal or whether a large building has multiple heights/parts.

Likewise, Copernicus DSM minus FABDEM terrain cannot be read as a surveyed building height without validating common vertical reference, alignment, acquisition compatibility, vegetation contamination, grid sampling and local error. A 30 m grid can mix multiple buildings and open ground. It may be investigated as a coarse neighborhood-scale check, but no such processing is implemented here.

## Integration gate

Do not code raster-to-building height assignment from these candidates. For sectioned building geometry, prefer explicit `building:part` geometry and tagged height/levels where available, or a building-scale source whose Moscow coverage, epoch, vertical semantics and redistribution rights are verified. Keep unknown heights unknown; render-only fallback values must remain labeled as estimates. GHSL and Copernicus may be reconsidered only for clearly aggregated city context or documented quality checks.
